# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive; harassment and personal attacks are not
tolerated; disagreements are argued with evidence about code, never about people.

Report conduct issues privately to the maintainers (see [SECURITY.md](SECURITY.md) for
the private-channel path). Maintainers will review and respond as promptly as they can,
and may edit, remove, or reject contributions and interactions that violate this code.
